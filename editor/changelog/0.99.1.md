# RPG Reactor 0.99.1 (in development)

Work since 0.99.0. The short version is in the [root changelog](../../changelog/0.99.1.md). Runtime **20261014.1**.

### Changed

- **Levels go to 9999** (`RR_LIMITS.ACTOR_LEVEL`, and the runtime's `maxLevel`, setup and `classParamAtLevel`). Class curves still store 999 levels (`RR_LIMITS.CLASS_CURVE_LEVEL`), or up to the class's target level when it is higher; past the last stored level a curve continues by its last step. The status windows give the level four digits.

### Fixed

- **A battle kept on another map no longer blocks battles elsewhere.** Start Battle on Map, random encounters and the battle screen asked whether any battle was running instead of one on this map. The kept battle now ends as an escape when another starts (`Game_Fight.endKept`); its units, music, followers and Tactical camera are left alone on the map the party is on, and its outcome waits for the party's return.
- **A party member added during a battle on the map joins it** (`Game_Fight.takeNewMembers`, after Change Party Member and Formation), on a free cell beside the leader; one who left and came back keeps their unit.
- **Action and First Person battles can be escaped by script.** `$gameFight.canRetreat()` / `commandRetreat()` work in these modes when the battle allows escape, ending with the escape message and the Escape branch. No control calls them yet.
- **Enemies placed on a Classic map stay defeated** after the battle, across map visits and saves, unless their In battle row says Comes back (`Game_Fight.setEventDefeated`, `eraseDefeated`).
- **A vehicle sliding along a closed map edge no longer leaves by the next border early.** A refusal at the border now leaves only by the border that refused (`pastSide` in `reactor_vehicles_drive.js`).
- **Copy Page and Paste Page in the Event Editor carry the page's 3D model.**
- **Editing an event on a 2D map no longer leaves an empty 3D sidecar,** so the map no longer reads as changed after Undo.
- **A damaged project lock no longer stops a project opening.** A lock that cannot be read and has not changed for 10 seconds is treated as stale.
- **Database › Tilesets:** the list row shows a new name as it is typed.
- **User Interfaces:** the Inspector drawer starts below the Layout toolbar instead of covering it, and its close button shows.
- **Database › Types:** below 980 px the five lists share two rows instead of scrolling sideways.
- **Database › Terms:** command fields go to three columns at 1300 px and two at 900 px, so values like `\i[604] EQUIPMENT` show in full.
- **Build › Door and Window frame:** a setting's field takes the rest of the row, so the Opens choice shows in full.
- **Import Project:** settings sit on one label and field grid and the log takes the height left, so the dialog fits 1366×768 without scrolling.
- **`nw-map-tool-switching.cjs`** follows the Models group's move to the Build bar.

### Changed

- **Maintainer docs stay short.** `docs/HANDOFF.md` holds only the cycle in progress, and `docs/STATUS.md` holds one validation bullet per area and the one open-work list. `editor/build-scripts/archive-handoff.cjs` moves finished handoff entries to `docs/archive/handoff/<version>.md`, `cut-release.cjs` runs it in every release commit, and `docs-budget.test.cjs` enforces the size limits listed in `docs/README.md`.
